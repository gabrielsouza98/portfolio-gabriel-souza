01 / EXPERIÊNCIA INTERATIVA

ParticleWall 3D

Movimentos que transformam uma parede.

Uma experiência visual de partículas controladas por gestos, pensada para usar a câmera como entrada e um projetor HDMI como saída. A proposta explora interação sem sensores dedicados.

  • JavaScript
  • Gráficos 3D
  • Câmera / webcam
  • Projeção HDMI
Conhecer o projeto ↗

O desafio

Explorar uma parede interativa usando os equipamentos disponíveis: notebook, projetor e celular como webcam.

Como funciona

A câmera fornece a imagem das mãos, a aplicação interpreta os gestos e atualiza a cena de partículas no navegador. O projetor exibe o resultado na parede.

  1. Capturar movimentos pela câmera.
  2. Relacionar os gestos à interação visual.
  3. Atualizar e projetar a cena de partículas.

O que este trabalho demonstra

Integração entre software e dispositivos, construção de experiências interativas em JavaScript e atenção à configuração da câmera e da projeção.

Projeto pessoal exploratório. O funcionamento depende de câmera, permissões e configuração do ambiente. Esta página apresenta o conceito; não executa a aplicação.

02 / INFRAESTRUTURA & REAPROVEITAMENTO

Servidor doméstico

Um novo propósito para um celular.

Configuração de um celular Android como servidor de arquivos doméstico. Com Termux e Copyparty, os arquivos podem ser acessados pelo navegador de outros dispositivos na mesma rede.

  • Android
  • Termux
  • Copyparty / Python
  • HTTP / rede local
Conhecer o projeto ↗

O desafio

Reaproveitar um celular para disponibilizar arquivos em casa, sem depender de um notebook ligado para essa função.

Como foi montado

O Termux oferece o ambiente de terminal no Android. Nele, o Copyparty, uma ferramenta baseada em Python, serve a pasta de arquivos por HTTP. Outros dispositivos acessam o endereço do celular pela rede local.

  1. Preparar o ambiente no Android com Termux.
  2. Instalar e configurar o Copyparty e a pasta compartilhada.
  3. Acessar os arquivos em outro dispositivo pelo navegador.

O que este trabalho demonstra

Uso de terminal, instalação de ferramentas, configuração de serviços HTTP, compreensão de endereços e portas na rede local e reaproveitamento de hardware.

Trabalho de configuração e integração com ferramentas existentes. O Copyparty não foi desenvolvido por mim. O acesso local foi colocado em funcionamento; não se trata de um serviço público hospedado neste portfólio.
